## نحوه ساخت APK

1. اندروید استودیو (Android Studio Ladybug یا جدیدتر) را نصب کنید.
2. این پوشه را با **Open** باز کنید (نه Import).
3. صبر کنید تا Gradle Sync کامل شود (اولین بار اینترنت لازم است برای دانلود وابستگی‌ها).
4. از منوی **Build → Build Bundle(s) / APK(s) → Build APK(s)** استفاده کنید.
5. فایل APK در مسیر زیر ساخته می‌شود:
   `app/build/outputs/apk/debug/app-debug.apk`

برای نسخه Release (قابل انتشار در بازار و مایکت):
- یک Keystore بسازید
- در `app/build.gradle.kts` بخش signingConfigs را تنظیم کنید
- سپس **Build → Generate Signed Bundle / APK**
